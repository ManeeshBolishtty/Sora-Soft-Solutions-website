# SORASOFT Solutions — website prototype V5

This is the V5 static website prototype for SORASOFT Solutions. It is a reviewable framework; company-specific content should be checked and updated before final publishing.

## Included
- `index.html` — page structure, SEO metadata, canonical URL and `WebSite` / `Organization` structured data.
- `style.css` — responsive visual design, stronger body typography, motion, section-specific styling and reduced-motion support.
- `script.js` — mobile navigation, scroll progress, reveal effects and interactive detail panels.
- `img/` — existing logo, symbol and favicon assets.
- `robots.txt` and `sitemap.xml` — basic crawl guidance and sitemap.

## Important SEO note
The website includes recommended on-page signals and structured data, but these do not guarantee a specific Google ranking or eliminate Google's spelling suggestions. After publication, verify the site in Google Search Console, submit the sitemap, inspect the canonical homepage and request indexing. Search changes may take time.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server for a more reliable local preview.
3. Check desktop, laptop, tablet and mobile widths, navigation, modal details and email links.

## Before publishing
- Review and replace generic company copy with the owner's approved final introduction, service details and facts.
- Confirm contact information and all claims about service scope.
- Keep the existing live website intact until the replacement has been reviewed.
- Back up the current GitHub Pages repository before replacing files.
- Preserve the existing custom-domain and HTTPS configuration; check the repository's CNAME and Pages settings before deployment.
- After publishing, verify `https://sorasoftsolutions.com/`, HTTPS, canonical URL, favicon, sitemap and Search Console.

This is a static front-end prototype. It does not include a backend, customer database, analytics tracker, authentication or a live SoraTrade product.
