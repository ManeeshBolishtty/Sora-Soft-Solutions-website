# SORASOFT Solutions Website

The official static website for SORASOFT Solutions.

## Files
- `index.html` — page content, metadata, structured data and section layout.
- `style.css` — brand styling, responsive layouts, visual effects, animations and reduced-motion support.
- `script.js` — mobile navigation, expertise detail dialogs, reveal-on-scroll behavior and dynamic footer year.
- `img/` — company mark, favicon, web manifest and organisation logo assets.
- `CNAME` — custom domain used by GitHub Pages.
- `robots.txt` and `sitemap.xml` — crawler guidance and the canonical homepage.

## Technology
This is a static front-end website built with HTML, CSS and vanilla JavaScript. Google Fonts are loaded for DM Sans and Manrope. No application server, database, authentication system or live SoraTrade service is included.

## Local preview
Open `index.html` in a modern browser. For a closer match to hosting behavior, serve the folder with a local static development server, such as VS Code Live Server.

## Deployment
The site is hosted with GitHub Pages and uses the custom domain in `CNAME`. Review changes on a staging branch before merging them into `main`. After publication, verify the custom domain, HTTPS, page layout, contact links, sitemap and favicon.

## Content notes
SoraTrade is described as in development and its interface is illustrative. Organisation names and logos in the professional-experience section are accompanied by a disclaimer that their display does not imply endorsement or a direct current engagement.
